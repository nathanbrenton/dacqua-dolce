Photo requirements · Quick reference

Accepted source typesPNG (.png), JPEG (.jpg/.jpeg), WebP (.webp), TIFF (.tif/.tiff)
Preferred source canvas1122 × 1402 px or larger · portrait ~4:5 · not mandatory
GUI upload limit64 MiB per image · larger originals: use ingest-drop/
Generated web filesPNG + lossless WebP · website max 1122 × 1402 px · thumbs max 384 × 480 px
More: dimensions, naming, archival and processing rules
  • Source validation: at least 16 px wide and 16 px high, at most 50 megapixels; supported folder-intake files are at most 256 MiB. The GUI enforces the lower 64 MiB limit.
  • Output dimensions are maximums: ImageMagick preserves the source aspect ratio, auto-orients, and does not crop or upscale. A smaller original stays smaller. A portrait ~4:5 source works best for existing product compositions.
  • Six artifacts per photo: unchanged archival master, website PNG, website lossless WebP, thumbnail PNG, thumbnail lossless WebP, and an integrity/metadata JSON manifest.
  • Filename convention: lowercase, underscores between fields, size 1-5/2-0, two-digit gallery position and revision. The form generates the name automatically. New Clack photos must explicitly use clack3 or clack5.
  • Refine/Essence example: refine_1-5_neoprene_clack5_archetype_system_01_v03.png
  • Harmony example: harmony_1-5_stainless_tank_02_v01.png (no valve/style fields).
  • Origin example: origin_remineralization_system_01_v02.png (no tank/valve fields).
  • Safety: originals are preserved. Preparing a batch does not publish; TEST publication needs separate review and approval. Nothing deploys automatically to PROD.

Tip: review the generated filename below before adding the photo; image roles and position control gallery placement, not the source filename.
